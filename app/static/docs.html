CIE-H14A Modbus Controller
메인 v1.0.0
개요 인증 에러 코드 엔드포인트 Health Check 시스템 상태 출력 제어 출력 토글 설정 조회 모니터링 SSE 스트림 사용 예제

API 문서

CIE-H14A 4채널 디지털 I/O 컨트롤러를 제어하기 위한 REST API입니다.

Base URL: http://localhost:5000
프로토콜: HTTP/REST
데이터 포맷: JSON

인증

현재 버전에서는 인증이 필요하지 않습니다.

주의: 프로덕션 환경에서는 적절한 인증 메커니즘을 추가해야 합니다.

에러 코드

HTTP 상태 코드 설명
200 성공
400 잘못된 요청 (파라미터 오류)
404 리소스를 찾을 수 없음
500 서버 내부 오류 (Modbus 통신 실패 등)
에러 응답 형식
{
  "error": "에러 메시지 설명"
}

엔드포인트

GET /health
Health Check

서버 상태 및 Modbus 연결 상태를 확인합니다.

응답 예제
{
  "status": "healthy",
  "modbus_connected": true
}
GET /api/status
시스템 상태 조회

전체 입출력(I/O) 상태를 조회합니다.

응답 예제
{
  "connected": true,
  "inputs": [false, true, false, false],
  "outputs": [false, false, true, false],
  "timestamp": 1729166400.123
}
필드 설명
  • connected (boolean): Modbus 연결 상태
  • inputs (array): DI0-DI3 상태 (4개 요소)
  • outputs (array): DO0-DO3 상태 (4개 요소)
  • timestamp (float): UNIX 타임스탬프
POST /api/output/<channel>
출력 제어

특정 출력 채널을 ON 또는 OFF로 제어합니다.

경로 파라미터
  • channel (integer): 출력 채널 번호 (0-3)
요청 본문
{
  "state": true
}
응답 예제 (성공)
{
  "success": true,
  "channel": 0,
  "state": true
}
POST /api/output/<channel>/toggle
출력 토글

특정 출력 채널의 상태를 반전(토글)합니다.

경로 파라미터
  • channel (integer): 출력 채널 번호 (0-3)
응답 예제
{
  "success": true,
  "channel": 1,
  "state": true
}
GET /api/config
설정 조회

현재 Modbus TCP 연결 설정을 조회합니다.

응답 예제
{
  "modbus_host": "192.168.10.105",
  "modbus_port": 502,
  "modbus_unit_id": 1,
  "modbus_timeout": 0.3,
  "poll_interval": 0.5
}
GET /api/monitor
모니터링 정보

API 서버의 상태 및 통계 정보를 조회합니다.

응답 예제
{
  "uptime": 3600.5,
  "total_requests": 1523,
  "failed_requests": 12,
  "success_rate": 99.21,
  "recent_1min": {
    "requests": 15,
    "failed": 0,
    "avg_duration_ms": 12.34
  },
  "recent_history": [...],
  "last_check": 1729166400.123
}
GET /api/events
실시간 이벤트 스트림 (SSE)

Server-Sent Events를 통해 실시간으로 I/O 상태 변화를 수신합니다.

Content-Type
text/event-stream
이벤트 데이터
{
  "connected": true,
  "inputs": [false, true, false, false],
  "outputs": [false, false, true, false],
  "timestamp": 1729166400.123
}
JavaScript 예제
const eventSource = new EventSource('/api/events');

eventSource.onmessage = function(event) {
  const data = JSON.parse(event.data);
  console.log('I/O 상태:', data);
};

사용 예제

Python

import requests

BASE_URL = "http://localhost:5000"

# 상태 조회
response = requests.get(f"{BASE_URL}/api/status")
status = response.json()
print(f"연결: {status['connected']}")

# DO0 켜기
requests.post(
    f"{BASE_URL}/api/output/0",
    json={"state": True}
)

curl

# 상태 조회
curl http://localhost:5000/api/status

# DO0 켜기
curl -X POST http://localhost:5000/api/output/0 \
  -H "Content-Type: application/json" \
  -d '{"state": true}'

# DO1 토글
curl -X POST http://localhost:5000/api/output/1/toggle

채널 매핑

디지털 입력 (DI)

채널 Modbus 주소 설명
DI00디지털 입력 0
DI11디지털 입력 1
DI22디지털 입력 2
DI33디지털 입력 3

디지털 출력 (DO)

채널 Modbus 주소 설명
DO08디지털 출력 0 (릴레이)
DO19디지털 출력 1 (릴레이)
DO210디지털 출력 2 (릴레이)
DO311디지털 출력 3 (릴레이)
중요: 출력 주소는 8부터 시작합니다 (0이 아님).
